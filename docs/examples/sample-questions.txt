1. 下列何者是 C 語言的關鍵字？
(A) main
(B) int
(C) printf
(D) scanf
答案：B
詳解：int 是 C 語言的保留字；main、printf、scanf 都是函式名稱。

2. 執行下列程式後，x 的值為何？
```c
int x = 3;
x += x++ * 2;
```
(A) 6
(B) 9
(C) 10
(D) 未定義行為
答案：D
詳解：同一個運算式中修改 x 兩次且沒有序列點，屬於未定義行為。

3. 下列哪些是迴圈敘述？（複選）
(A) for
(B) while
(C) switch
(D) do-while
答案：A、B、D
