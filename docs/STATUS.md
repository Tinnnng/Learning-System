## 開發環境與注意事項

- 啟動：`npm run dev`（http://localhost:5173）；手機同 Wi-Fi 用 `npm run dev:lan`（只綁 Wi-Fi IP，避開 Radmin VPN／Tailscale）。
- 測試：`npm test`（後端 133、前端 13 個測試）；改 API 後 `npm run gen:api`；改 models 後產生 migration 並 `npm run migrate`。
- 截圖自檢：先把 `data/` 複製到暫存區、用 `LS_DATA_DIR` 指向副本再啟動後端，**不要碰真正的資料庫**；`frontend/scripts/screenshots.mjs`。
- 呼叫真的 AI（系統內 AI）會花使用者的 Claude 額度：每次 AI 評分約 0.004 美元、標一科知識點約 0.01～0.03 美元。測試一律用 `FakeProvider`。
- Windows 細節：uvicorn 要連子程序一起關；大型 Bash heredoc 常失敗，改用 Write 寫檔或 Python 腳本；Python 腳本裡的 `"\n"`、`\d` 跳脫要小心。
- 結束工作前把開發伺服器關掉（目前沒有在跑）。
